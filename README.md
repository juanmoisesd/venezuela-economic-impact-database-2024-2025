## Description

This database compiles key economic indicators and principal influencing factors for Venezuela's economy during 2024-2025. Variables include: GDP growth rate, inflation rate, unemployment rate, official exchange rate (VES/USD), oil production (bpd), poverty rate, foreign exchange reserves, public debt (% of GDP), trade balance, remittances, FDI inflows, and fiscal deficit.

Key influencing factors: oil sector crisis, hyperinflation management, dollarization, US sanctions, migration crisis, parallel economy, and economic recovery indicators.
